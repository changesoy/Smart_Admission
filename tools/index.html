数据工具台

所有可视化页面都从 Vite 开发服务器提供，统一用 npm run ui 打开本页。

学区边界网络

学区边界点选编辑器
点选拓扑边生成学区草稿，可校验并直接写入 data/zone_specs.v2.json。 真实数据模式需先运行生成器。

路网处理

路口诊断与裁定
A 接近交点 / B 欠伸 / C 过冲 / D 共线重叠 / E 无交点，可点选定位。 由 junction-diagnose 与 build-intersections 生成。
路网改动比对
两版 roads.geojson 叠加，查看新增、删除与位移。由路网处理脚本生成。

区界比对

两套区界叠加比对
旧 zones.geojson 与新边界的形状与面积差异。
边界探针
按四至文本逐段核对边界要素，用于 B 侧裁定复核。
reports/ 下的页面不是源码，由脚本运行后生成，未生成时打开会 404。 常用命令：npm run import:network（路网全流程）、 npm run diagnose:junctions（只出诊断）、 npm run cli -- network:generate --effective-date <日期> --write（生成学区网络）。
