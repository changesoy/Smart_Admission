## 2. 总体处理原则

1. `source/学区.txt` 中新增学区作为本次权威新增边界。
2. 新增学区本身不做 `simplify`、`buffer`、坐标取整、平滑或自动吸附。
3. 对于新增学区与现有学区的面积重叠：
   - 如果是成片重叠，按确认后的归属裁剪原有学区；
   - 如果是边界狭长碎片，按新增学区边界保留原则，从现有学区中扣除碎片；
   - 不从新增学区中删除任何已确认属于新增学校的区域。
4. 修改时只调整受影响现有学区的 `geometry`，不修改它们的 `properties`。
5. 修改后所有学区必须保持合法 `Polygon` 或必要时合法 `MultiPolygon`；若出现极小孤岛，应单独列出后再决定是否删除，不能自动清理。

## 5. 推荐执行顺序

### 第一步：读取并固化原始几何

在执行任何修改前，先保存以下原始几何：

```text
zone_003 山东省泰安第六中学学区
zone_004 山东省泰安东岳中学学区
zone_006 山东省泰安第六中学新校区学区
zone_031 泰安市泰山区凤台中学学区
zone_034 山东省泰安南关中学学区
zone_035 泰安市泰山区泰前中学学区
迎春学校新增 Polygon
兴隆校区新增 Polygon
```

所有差集必须基于原始几何计算，避免前一步裁剪影响后一步判断。

---

### 第二步：新增两个学区

新增：

```text
山东省泰安迎春学校学区
山东省泰安东岳中学兴隆校区学区
```

新增时只把 `LineString` 改为 `Polygon`，坐标顺序不变。

---

### 第三步：裁剪迎春学校涉及的现有学区

按以下顺序处理：

```text
1. zone_004 = zone_004 - 迎春学校
2. zone_034 = zone_034 - 迎春学校
3. zone_006 = zone_006 - 迎春学校
4. zone_003 = zone_003 - 迎春学校
```

其中：

- `zone_004` 的 224,624 平方米成片重叠必须删除；
- `zone_034` 的 18 块重叠建议先输出坐标级方案，其中最大 1,181 平方米块需要人工确认；
- `zone_006` 和 `zone_003` 主要是边界碎片，可按新增迎春边界直接裁剪。

---

### 第四步：裁剪兴隆校区涉及的现有学区

按以下顺序处理：

```text
1. zone_031 = zone_031 - 兴隆校区
2. zone_035 = zone_035 - 兴隆校区
```

这些均为狭长边界碎片，建议按新增兴隆校区边界保留原则处理。

---

### 第五步：检查是否产生孤岛或异常 MultiPolygon

对以下裁剪后的学区重点检查：

```text
zone_004
zone_034
zone_006
zone_003
zone_031
zone_035
```

检查内容：

```text
1. 是否仍为有效 Polygon 或 MultiPolygon；
2. 如果变成 MultiPolygon，是否存在极小孤岛；
3. 如果存在极小孤岛，记录面积和位置，另行决定是否删除；
4. 不得在本轮自动删除孤岛。
```

## 6. 验收标准

修改完成后应满足：

### 6.1 几何合法性

```text
所有 Feature 都能被 GeoJSON 正常解析；
所有 Polygon / MultiPolygon 均为 valid；
所有 Polygon 外环首尾坐标完全一致；
无自相交、无空 geometry。
```

### 6.2 新增学区关系

```text
山东省泰安迎春学校 与 山东省泰安东岳中学兴隆校区 面积重叠为 0。
```

### 6.3 与现有初中学区关系

以下组合面积重叠应为 0，或仅剩浮点级误差：

```text
迎春学校 vs zone_004 东岳中学
迎春学校 vs zone_034 南关中学
迎春学校 vs zone_006 第六中学新校区
迎春学校 vs zone_003 第六中学
兴隆校区 vs zone_031 凤台中学
兴隆校区 vs zone_035 泰前中学
```

建议容差：

```text
单组重叠面积 < 0.01 平方米
```

如仍存在大于 0.01 平方米的面状重叠，应继续输出坐标级修正方案。

### 6.4 不应修改的内容

不得修改：

```text
未列入本规划的其他学区 geometry；
任何现有学区的 properties；
Feature 原有排列顺序，除非是在末尾追加新增学区；
新增学区原始坐标精度。
```

不得执行：

```text
simplify
buffer
坐标取整
自动吸附
自动平滑
自动删点
自动清理孤岛
```
