# 后续扩展方向

> 当前为阶段性原型，以下为可选的演进方向，按主题归类，不代表排期。

---

## 一、数据

1. **数据真实化** — 接入教育主管部门发布的真实学区边界与政策数据（当前仍有待补占位内容，见 `npm run check:release`）。当前阶段先解决"边界可校验、可复核"：同学段学区之间的重叠与缝隙由脚本自动检测并接入 `npm run check`，边界绘制走固定的 QGIS 工作流（见 [完善规划.md](../完善规划.md) 的 P0-6）。
2. **多区域可迁移** — 通过更换 GeoJSON 与政策 JSON 实现区域间快速迁移，前端零改动。

## 二、能力

3. **后端能力扩展** — 在保持代理职责清晰的前提下，逐步把数据下发与统计改为接口形式。
4. **在线地理编码** — 已通过后端 `/api/search` 代理天地图搜索实现，可进一步扩展为完整地理编码服务（含逆地理编码）。
5. **录取建议模拟** — 基于历年录取分数与积分规则，实现择校参考建议。
6. **学位预警** — 基于学位资源数量与适龄儿童数据，提供动态预警。
7. **辟谣模块** — 接入 `rumors.json`，提供谣言查证与辟谣信息展示。

## 三、体验与交付

8. **可访问性优化** — 高对比度模式、无障碍标签（ARIA）、键盘导航。
9. **移动端优化** — 增强触摸交互（双指缩放、长按查询）、PWA 离线缓存。
10. **离线部署支持** — 将 CDN 依赖本地化到 `vendor/` 目录，支持内网/离线环境。
